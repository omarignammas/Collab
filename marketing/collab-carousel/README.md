# Collab marketing carousel

An eight-slide English product carousel built for LinkedIn and X.

- Canvas: 1080 × 1350
- Format: portrait 4:5
- Story: problem → widget → voice → connected context → Focus Rooms → reports → analytics → CTA
- Product visuals: Collab desktop, widget, voice assistant, Focus Room and decision report

Open `index.html?slide=1` through `index.html?slide=8` to preview individual slides.

## Deliverables

- LinkedIn document carousel: `../../output/pdf/collab-marketing-carousel.pdf`
- Individual slide archive: `collab-marketing-carousel-images.zip`
- Individual PNGs: `slides/collab-carousel-01.png` through `slides/collab-carousel-08.png`
- Suggested launch caption: `post-copy.md`
